# hci-lernort-finder
Das Projekt "Lernort-Finder" im Rahmen der Vorlesung Human Computer Interaction an der OTH Regensburg

# Annahme (vor Erhebung): Nutzungskontext nach ISO 9241-210

| Element | Beschreibung |
|---|---|
| **Aufgaben** | Entscheiden, wo man heute lernt; hinkommen; einen Platz finden; allein oder mit der Gruppe lernen; ausweichen, wenn es voll ist |
| **Arbeitsmittel** | Laptop (braucht Strom und WLAN), Bücher und Skripte, Kopfhörer, Smartphone, Google Maps, WhatsApp-Gruppe („Ist in der Bib noch was frei?“) |
| **Physische Umgebung** | Lautstärke, Licht, Öffnungszeiten, Entfernung, Wetter (draußen lernen) |
| **Soziale Umgebung** | Andrang in der Prüfungsphase, Lerngruppen, Regeln wie „Sprechen verboten“, Konsumdruck im Café |

# Ziel der Primary Research Methoden:
Das Ziel ist herauszufinden, wer welches Problem bei der Lernortsuche hat, wie oft und wie stark
